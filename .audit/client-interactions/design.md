# Accepted interaction design

Use candidate A as the base. Root and independent gpt-6-luna judge scored both candidates 5/5. Both compared a unified lazy list against a coordinated collapsing header and selected the former. A gives the clearest cache-anchor and gesture ownership contract. Graft B's explicit retention of leading metadata during bounded serialization, identity-based internal restoration and status/footer-based pagination. Parent model identity was not exposed, so the judge family check could not be verified.

Profile supplies its existing header, compact actions, tabs and Activity filters as one stable non-scrolling leading item to FeedScreen. Remove the 380dp cap and independent header scroll. About uses one ordinary LazyColumn with the same leading content and About body, with no nested vertical scroller or feed request. Nonsticky tabs are accepted for this bounded correction. Header and posts move together; ordinary posts can occupy the full reading area after scrolling.

FeedScreen gains one optional composable leading-content slot. A private viewport adapter owns mixed-list/status translation. Profile callers never supply raw prefix counts. Existing notices and pending-arrival controls remain discoverable in the feed's existing outer chrome rather than being buried inside an offscreen profile header. FeedPager, FeedCache, StatusProjection, membership, cursors, cache identity and lifecycle remain their existing owners.

Existing FeedSnapshot items/index/offset remain status coordinates. Add an optional explicit leading-item anchor for header-visible restoration, with nonnegative offset validation. Preserve it when bounding and serializing snapshots. Translate mixed-list positions before saving and after restoration. Restore a status by identity after projection, choosing a surviving neighbor with zero offset if the saved identity is deleted. If cache truncation removes the anchor, reset its pixel offset. Never reuse header pixels as status offset. Legacy snapshots without a leading anchor remain status positions; a cache miss opens at the header. Wait for and clamp current leading-item measurement before restoring its offset. Do not save the default position over a snapshot while restoration is incomplete.

Use the same logical reading-older predicate for stream events, retry, foreground and periodic refresh. Header-visible means not reading older. Pending reveal scrolls to the first status after the prefix. Pagination uses visible status/footer and row count, preserving ready/busy/error/exhaustion gates. Notifications and feeds without leading content retain their behavior.

Home selection becomes an explicit three-case UI value owned by AppShell outside key(route,tab), inside the existing account/instance/authorization lifetime. Preserve Home/Local/Federated source mapping, guest Local default, large-text selector fallback and route-stack behavior. Do not keep hidden feeds running just to retain the selector. The current request does not promise process-restart persistence or new Profile subtab persistence.

Use a flexible Edit/Follow primary button beside equal 48dp QR and Share icon targets. Keep Favorites/Bookmarks as secondary actions and existing overflow/auth/busy/URL validation. Large text or narrow width may put the primary on its own line with balanced secondary controls. Preserve accessible QR and Share labels and all destinations.

Only the image viewport accepts single-finger vertical dismissal. One gesture owner chooses undecided, horizontal pager, transform or vertical dismissal after touch slop. Either vertical direction moves the image with the finger; a short drag or cancellation returns to zero, a sufficient drag animates outward and invokes onDismiss once. Distance threshold is symmetric and bounded by a fraction of the viewport and a dp cap. Velocity completion is optional unless native evidence requires it. Zoomed or multiple-pointer movement belongs to transformation, and a new pointer cancels dismissal. Horizontal-dominant movement stays with HorizontalPager. Page changes, external zoom and inactive pages must cancel stale dismissal. Preserve double tap, zoom bounds, page ordering, native video/audio, ALT scrolling, save state and captured retry target.

Root owns native tests, test account, Xcode DerivedData, versioning, integration, reviews and Release installation. Separate isolated implementation owners cover the disjoint profile/navigation/cache files and gallery gesture files, each with related shared tests. The first owner was told to stop at Unit1 before the gallery owner started. This improves throughput without shared writes or a changed behavior contract. Root reruns the original five failing native checks and the passing zoom/paging counterexample, adds restoration/short-drag checks, inspects normal and large-text screenshots, runs shared tests and builds, and records physical startup only if the device allows it.

The original no-schema-migration and separately scrolling header choices applied to earlier bounded corrections, as lineage.md documents. The user's current explicit correction supersedes that scope. No additional permission is required for this requested layout and state fix.

# QuanToot 界面重构验证

预览里的页面来自运行中的客户端。首页对比使用同一台 iPhone 模拟器、同一账号和同一条嘟文。编辑器截图使用未发布的本地草稿。

应用内使用正式 QuanToot 图稿的 192 像素版本，保留纸色底与彩色圆环。桌面图标沿用相同原稿。接入后重新构建了双端客户端，并在模拟器上复查了首页、欢迎页和 Android 深色侧边导航。

## 验证结果

| 环境 | 结果与覆盖范围 |
| --- | --- |
| 共享模块 | 167 项测试全部通过。覆盖时间线分页、发帖载荷、会话和帖子状态等既有行为，以及操作栏计数的显示边界。 |
| iPhone 17 Pro，iOS 26.4 | 15 项常规界面测试通过。覆盖切换及恢复时间线、搜索结果往返、草稿、媒体查看、资料页滚动位置、通知和设置导航。最终构建再次通过搜索返回与实例选择两项测试。 |
| iPhone 17 Pro，深色与辅助功能大字号 | 3 项测试通过。时间线标签保持单行和至少 44 点的触控高度，跨页面返回后选中项仍可见。资料页操作和会话正文可正常访问。 |
| iPhone 17e，游客 | 2 项测试通过。游客可选择实例、阅读公开嘟文，在发帖入口重新确认同一实例后回到本站时间线，亦可从设置子页逐级返回。 |
| Android API 37 模拟器 | 调试版安装并启动成功。通过系统界面检查了首页点按回顶、横屏侧边导航与发帖入口、深色阅读、游客通知和搜索的登录引导，以及返回公开时间线。 |

Android 构建和共享测试命令为 `./gradlew :shared:testAndroidHostTest :androidApp:assembleDebug`。iOS 界面用例位于 `iosApp/QuanTootUITests`，可在 Xcode 的 `QuanToot` scheme 中运行。登录场景使用已登录的模拟器，游客场景使用单独的模拟器。

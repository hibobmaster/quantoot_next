# 客户端功能对照

下文记录 0.6.1 至 0.6.5 的验收结果。已纳入版本控制的原始审计材料可在提交 `65b5fa2` 中查阅。运行 `git ls-tree -r --name-only 65b5fa2 .audit` 可列出文件。

0.6.5（11）修复 Profile 分类切换和设置子页面导航。个人资料区、固定分类栏和正文由同一个滚动控制器协调，切换 Posts、Media、Featured、Activity 或 About 时保留资料区收起程度，正文从分类开头显示；空列表也能继续收起资料区。切换前保存并关闭旧列表，缓存恢复保留帖子坐标、分页游标和来源隔离。设置子页面使用对应的本地化标题和统一返回入口，返回先到设置列表。

本轮 166 项共享测试全部通过，Android unsigned Release 和签名 arm64 iOS Release 构建成功。集成后的 14 种核心与回归场景通过，覆盖分类、筛选、账号页面往返、Home 栏目保留、通知、外观以及系统最大辅助功能字号。连同前期设置检查，本轮跨阶段共覆盖 18 种应用场景。独立滚动原型的 10 种检查单独记录，未计入应用场景。输入或测试定位失败的原始回执均保留，已有实例的游客测试资格检查按预期跳过，不计为通过场景。本轮没有新增服务器发帖、编辑、删除或相册写入。

源代码快照为 `c6d0b26`，签名包为 `iosApp/build/releases/QuanToot-0.6.5-11.ipa`。版本、签名、Keychain 访问组、目标设备授权、125 个源文件哈希、压缩包完整性及主程序一致性均已校验。当时实体 iPhone 18 Pro 的开发连接返回 CoreDevice 4016，本轮真机覆盖安装与启动验收因此中止。硬件键盘跳转到未组合的 Profile 行也未纳入本轮验收。

0.6.4（10）修复三处阅读细节。帖子详情使用普通卡片底色，定位时仅显示短暂的中性细描边，随后完全淡出；刷新和内容编辑不会重新触发提示，定位回复时也不会同时高亮主帖。Profile 标签栏取消默认的 52pt 起始留白，Posts 打开即对齐左侧，保留后续分类的横向滚动。开源许可移除已不再打包的文楷字体条目，保留 Kotlin、Compose Multiplatform、Ktor、Coil 和 QRose 的许可链接。

本轮在原有登录态下验证了 8 种原生场景，跨深色、浅色及辅助功能大字号共执行 12 次，全部通过。共享测试 131 项全部通过，Android unsigned Release 和签名 arm64 iOS Release 构建通过。0.6.4（10）已覆盖安装并启动于实体 iPhone 18 Pro，版本回读一致，实际截图确认时间线正常显示。源代码快照为 `9845683`，安装包为 `iosApp/build/releases/QuanToot-0.6.4-10.ipa`。本轮没有新增发帖、编辑、删除或相册写入。

0.6.3（9）修复了资料页和阅读手势。个人资料、按钮、分类和帖子使用同一条滚动列表，资料头可以滚出视野。编辑或关注与 QR、分享组成紧凑操作行，大字号时自然换行。返回帖子或切换底部栏目后保留 Home、Local、Federated 的选择。全屏图片支持上下拖动关闭，短拖回弹，同时保留放大拖动、左右翻页及原有保存流程。共享测试 131 项、主原生回归 21 项均通过，另有一项暗色大字号资料页检查通过。Android Release 和签名 arm64 iOS Release 均已构建。

0.6.3 的源代码快照为 `fe8cd3b`，安装包为 `iosApp/build/releases/QuanToot-0.6.3-9.ipa`。签名、版本、Keychain 访问组、压缩包完整性和主程序一致性均已校验。机主解锁后，实体 iPhone 18 Pro 的开发连接恢复，已成功覆盖安装并启动。设备回读确认版本 0.6.3、构建号 9，实际截图确认时间线正常显示。此前的连接失败回执作为历史证据保留。

资料页阅读位置在缓存中区分资料头与帖子，旧缓存仍按原来的帖子位置读取。About 不再嵌套独立的垂直滚动区域。保留既有来源、账户隔离、分页与状态同步的归属。部分早期截图显示恢复的历史缓存。

额外的双击缩放探针受到测试输入限制。XCTest 合成点击的间隔为 0 毫秒，低于手势框架的 40 毫秒下限，因此主回归排除了此探针。

0.6.2（8）继续对照原版 Flutter 客户端改进界面和发帖流程。原版位于 `/Users/bobmaster/Projects/quantoot`，本轮未修改原版仓库。

共享测试共 112 项通过，失败、错误和跳过均为零。最终 11 项只读 iOS 场景全部通过。Android Release 和签名 iOS Release 构建均通过。0.6.2（8）已覆盖安装到实体 iPhone 18 Pro，设备回读确认版本。当时手机锁定，最后的启动和画面验收因此中止。IPA 为 `iosApp/build/releases/QuanToot-0.6.2-8.ipa`，源代码快照为 `3441b80`。

真实账号验证使用 iPhone 17 Pro 模拟器上已有的 ai 测试账号，没有清除其存储。创建的两个临时帖均为没有其他收件人的 direct 帖子。第一个用于恢复并校准原生测试，第二个完成了一次连续的发布、编辑、重启回读和删除流程。随后分别通过成功的认证精确链接搜索及账户时间线读取确认二者已消失。没有修改或删除原有帖子，也没有提取或记录令牌。

图片保存验证新增了一个系统相册资源。选定的 JPEG 保存后仍为 745 × 1280，压缩图像数据及全部非 EXIF 字节与原图一致。Photos 调整了 EXIF，因此完整文件哈希不同。该结论只覆盖实际验证的这一张 JPEG，可使用 `scripts/verify_saved_photo.py` 复查。

已有投票帖的编辑暂时通过浏览器完成。当前 Mastodon REST 模型不返回恢复全部投票设置所需的信息，直接提交可能重置隐藏计票等设置。客户端显示说明并阻止该提交。新建投票仍保留现有功能，本轮未联网执行投票、举报、关注请求处理或账户资料设置写入。帖子发布后的可见性由服务器固定，编辑器明确显示这一限制。

| 需求 | 当前行为 |

同步继续由 StatusProjection、FeedPager 和 FeedCache 分别管理内容、成员顺序与游标。前台每 20 秒进行 REST 补偿，断线重连后也会补齐数据。后台取消活动任务。引用仅在服务器返回 accepted 时展示内容，其余授权状态保留不可用提示。画廊保存仍只支持图片。

0.6.1 的历史基线包括 90 项共享测试、7 项只读原生场景和一次设备安装验证。
